批量加水印（桌面版）

一、功能
  给一个文件夹里的一批图片，在选定的角落盖上标志。
  图片分辨率、横竖比例、方向各异都行；水印比例按图片较短边计算，观感一致。
  纯本地运行，不联网、不上传。

二、运行（重要：双击「启动.bat」）
  ⚠ 这台机器 .pyw 的系统关联指向一个失效的旧程序，所以不要直接双击 watermark.pyw，
    一律双击「启动.bat」，它会用正确的 pythonw 启动。
  界面为深色墨绿风格，支持高 DPI，不会发糊。

三、操作
  0. 顶栏菜单（界面内自绘，与深色主题一致）：
     · 文件：打开图片文件夹…（Ctrl+O）/ 打开输出文件夹 / 退出
     · 设置：更换标志图片… / 输出位置与导出格式… / 清除本文件夹的增强默认
     · 关于：关于本工具…（版本号与项目链接）/ 打开配置与日志目录
  1. 点「选择文件夹」，选中图片文件夹（支持 PNG/JPG/WebP/BMP）。
  2. 调右侧参数，左侧实时预览。
  3. 预览交互：
     · 放大缩小：滚轮，或点 − / ＋ 按钮（以鼠标位置为中心）。
       主窗口的放大只用缩略图，不重新读原图，所以不论图多大都不卡；
       一直放大到能看见像素感也没关系。
     · 平移：放大后按住左键拖动（已限制不会拖出可视区）。
     · 复原：双击画面，或点「恢复」按钮。
     · 翻页：← → 方向键，或「← 上一张 / 下一张 →」按钮；翻页自动复原缩放。
     · 查看原图：点「查看原图」按钮，会新开一个窗口显示原图真实效果。
       渲染在后台进行，不阻塞主界面；大图会先降到内部 2200px 再合成，
       所以 5000 万像素级的图也能很快打开、拖拽不卡。
       窗口里支持滚轮缩放、拖动、双击恢复，以及「适应 / 100% / 放大 / 缩小」。
     相邻图片后台预解码，翻页很快。
  4. 点「导出全部」。

四、参数
  【水印位置】左上 / 右上 / 左下 / 右下。
  【大小与留白】标志宽度、留白、不透明度。滑块拖动，也可在数字框直接输入。
  【深色底适配】应对整体偏暗或偏亮的底：
     · 自动：检测背景明暗，深色底给校徽垫圆底、文字反白；浅色底保持原色。
     · 原色 / 反白：整批强制用其中一种。
     · 圆底浓度 / 圆底大小（0 贴校徽外径，负值收在内）/ 深浅判定阈值。
  以上三项是常规设置，多数图片靠「自动」就够了。

五、单张增强（仅对当前这一张）
  个别难搞的图（黑白错杂、颜色杂乱、明暗交错），用这里。
  【水印黑白】跟随全局 / 自动 / 原色 / 反白——随时可设，只作用本张。
     用于给某一张单独指定用原色版还是反白版，不受全局「自动」影响。
  【描边与毛玻璃】需打开「启用」才显示：
     · 描边：无 / 白 / 黑 / 双色（白内黑外，最稳），宽度可调。
     · 毛玻璃底板：在标志下垫一块「背景模糊 + 薄白」的圆角板；
       雾面浓度 / 模糊强度 / 内边距 / 圆角 / 边缘淡出都可调（默认值是常用的一套）。
  三层的优先级：全局默认 → 本文件夹默认 → 本张单独设置（后者覆盖前者）。
  · 翻页时自动切到该图自己的设置。
  · 「把当前增强套用到全部图片」：给文件夹里现有每张图都写一份。
  · 「存为本文件夹默认」：把当前这套当作本文件夹的默认；
    没单独设过的图（包括以后新加进来的）都用它。

六、导出（点顶部「导出全部」弹窗里选）
  点「导出全部」会弹出「导出设置」窗口，里面集中了输出的所有选项：
  【输出位置】默认「原文件夹内的『已加水印』子文件夹」；可「更改位置」或「恢复默认」。
     输出为图片文件夹（不是压缩包）。
  【图片格式】原格式 / JPEG / PNG / WebP。
     · 原格式：按每张图原来的扩展名输出（PNG 保透明，其余转 JPEG）。
  【质量】滑块 50~100，用于 JPEG 与 WebP（越低体积越小）；PNG 无损，不受影响。
  窗口底部会实时显示「共 N 张，输出为 …，质量 …，→ 目录」。
  位置、格式、质量都按文件夹记住，下次同文件夹带出。

七、配置与日志（不会写入你的图片文件夹）
  · settings.json：按文件夹保存你的设置（含每张图的增强、文件夹默认、输出位置、导出格式），
    下次打开同一文件夹自动恢复。自动保存，关窗口前也会落盘。
  · logs/app.log：运行日志（启动、打开文件夹、导出、错误）。
  · 两者都在本工具目录下；菜单「关于 → 打开配置与日志目录」可直接打开。
  · 日志超过 2MB 会自动轮转一份 app.log.1。

八、文件说明（都要带上，别拆散）
  watermark.pyw      主程序（界面）
  watermark_core.py  核心图像处理
  watermark_store.py 配置与日志
  logo_placeholder.png  占位标志（可换成自己的 logo.png）
  启动.bat           启动入口

九、换标志 / 换机器
  换标志：菜单「设置 → 更换标志图片…」选一张（会拷成工具目录下的 logo.png）；
         或直接把图片命名为 logo.png 放进来。程序自动拆分校徽与文字。
  换机器：若 Python 装在别处，改「启动.bat」里 PYW= 的路径。
  依赖：Python + Pillow + CustomTkinter（本机已装好）。

十、排错
  双击启动.bat 若没弹窗，看本目录有没有生成「启动错误.log」，或查 logs/app.log。
