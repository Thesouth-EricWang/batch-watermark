水印标志 · 输入说明
==================

一、为什么要两版
  工具会在深色底图片上用"白字版"，在浅色底图片上用"原色版"，
  自动切换（判断水印区域背景的明暗）。
  所以标志最好准备两张：一张原色、一张白字。

  如果只给一张原色版，工具会自己"凑合"：
  深色底时把文字改成白色、并在校徽下垫一层圆底。
  这对"深色字 + 透明底"的标志有效；对已有的白字/彩色标志就不合适了，
  所以标志颜色一变，最好直接给两版，而不是让工具去猜。


二、文件怎么放
  放在程序（exe）同一目录下，或菜单里直接选：

    浅色底用（原色）  命名 logo_light.png   或 菜单 设置→更换浅色底标志
    深色底用（白字版）命名 logo_dark.png    或 菜单 设置→更换深色底标志

  · 只放 logo_light.png 也行：深色底会退回"文字改白+垫圆底"的老办法。
  · 菜单里选过的图会被拷到程序目录并记进配置，下次自动用。
  · 这两个文件不会进 Git 仓库（.gitignore 已排除），属于你本地素材。


三、合格的输入长什么样
  1. 格式：透明底 PNG（不能是白底、不能是 JPG）。
     白底图贴上去会带一块白方块。
  2. 构图：横版，左边一个方形/圆形的"校徽"，右边一行"文字"。
  3. 中间要有明显空隙：工具靠"最宽的一段空白"把标志切成两半
     （校徽 / 文字）。两者挨在一起、或文字里出现比这更宽的空白，
     都会切错。
  4. 分辨率：建议高一点（长边 1000px 以上），缩小时更清楚。
  5. 颜色：
     · 浅色底版 —— 用深色/彩色（如深蓝），保证在白纸上看得清
     · 深色底版 —— 用白色，保证在黑底上看


四、深色底那张，白底要不要自己加？
  两种做法都行：

  A. 自己加好（推荐）
     把校徽下面那圈白底直接画进 logo_dark.png。
     工具会原样使用，不再改动颜色，也不再额外垫底。
     （若还想让工具垫，把「圆底浓度」调到 0 即可关掉。）

  B. 交给工具垫
     只给白字、不带白底的版本，在「圆底浓度 / 圆底大小」里调那层圆底。
     注意：圆底是垫在"校徽"下面的，文字部分不会被垫。


五、常见问题
  · 贴上去有白方块 → 你的图不是透明底，请重新导出透明 PNG。
  · 深色底上标志糊了 → 大概率是校徽本身是深色。给它单独做一张白字版
    （或把校徽也改浅），比让工具垫底色更干净。
  · 标志被切成奇怪的两块 → 构图里没有明显空隙，或空隙位置不对。
    把校徽和文字之间留出明显的空白再导出。
  · 想要的效果和预览不一致 → 预览用的是缩略图；点「查看原图」看真实效果。


六、一句话
  标志怎么配色、白底要不要，**你自己决定并画进图里**；
  工具只负责"按背景明暗选对应的那一张、按比例放到角落"。
