# 批量加水印（桌面版）

给一个文件夹里的图片批量盖上标志，角落、大小、深色底适配、描边、毛玻璃底板都能调。

Python + CustomTkinter 桌面程序，**纯本地运行，不联网、不上传图片**。

> 仓库里带的是**占位标志**（不含任何机构信息）。换成自己的标志：菜单 **设置 → 更换标志图片…**，或直接把图片放到工具目录下的 `logo.png`。

---

## 拿来就用

需要本机有 **Python 3**，并装好两个库：

```
pip install pillow customtkinter
```

然后**双击 `启动.bat`**。

> ⚠ 不要直接双击 `watermark.pyw`。部分机器上 `.pyw` 的系统关联指向一个失效的旧程序，双击会没反应；`启动.bat` 用正确的 pythonw 启动，绕开这个坑。

---

## 怎么用

1. 点 **选择文件夹**（或菜单 文件 → 打开图片文件夹，Ctrl+O），选中装有图片的文件夹。支持 PNG / JPG / WebP / BMP。
2. 右侧调参数，左侧实时预览。
3. 翻看各张：`←` `→` 方向键，或点 **上一张 / 下一张**。
4. 点 **导出全部**，在弹出的窗口里选输出位置与格式。

### 预览操作

| 操作 | 方式 |
|---|---|
| 放大缩小 | 滚轮，或 `−` / `＋`（以鼠标位置为中心） |
| 平移 | 放大后按住左键拖动 |
| 复原 | 双击画面，或点 **恢复** |
| 看真实效果 | 点 **查看原图**，新窗口后台渲染 |

预览的放大只用缩略图，图再大也不卡；要看原图细节点「查看原图」。

## 参数

### 常规（整批生效，按文件夹记住）

- **水印位置**：左上 / 右上 / 左下 / 右下
- **标志宽度、留白、不透明度**：滑块拖动，也可在数字框直接输入
- **深色底适配**：检测背景明暗，深色底给校徽垫圆底、文字反白；浅色底保持原色
  - 自动 / 原色 / 反白 三档；圆底浓度、圆底大小、深浅判定阈值可调

### 单张增强（默认收起，只作用当前这一张）

个别难搞的图（黑白错杂、颜色杂乱、明暗交错）再用：

- **水印黑白**：跟随全局 / 自动 / 原色 / 反白
- **描边**：无 / 白 / 黑 / 双色（白内黑外，最稳），宽度可调
- **毛玻璃底板**：垫一块「背景模糊 + 薄白」的圆角板，雾面浓度 / 模糊强度 / 内边距 / 圆角 / 边缘淡出可调

设置是**三层**的，后者覆盖前者：

```
全局默认  →  本文件夹默认  →  本张单独设置
```

- **把当前增强套用到全部图片**：给文件夹里现有每张图各写一份
- **存为本文件夹默认**：没单独设过的图（含以后新加的）都用它

## 导出

点 **导出全部** 弹窗里选：

| 项 | 说明 |
|---|---|
| 输出位置 | 默认「原文件夹内的『已加水印』子文件夹」 |
| 图片格式 | 原格式 / JPEG / PNG / WebP |
| 质量 | 50~100，用于 JPEG 与 WebP；PNG 无损 |

输出是**图片文件夹**，不是压缩包。

## 配置与日志

都在**本工具目录**下，**不会写进你的图片文件夹**：

- `settings.json`：按文件夹保存设置（含每张图的增强、文件夹默认、输出位置、导出格式）。自动保存，关窗口前也会落盘。
- `logs/app.log`：运行日志。超过 2MB 自动轮转。

菜单 **关于 → 打开配置与日志目录** 可直接打开。

## 目录结构

```
watermark.pyw        主程序（界面）
watermark_core.py    核心图像处理（无 GUI 依赖，可单独测）
watermark_store.py   配置与日志
logo_placeholder.png  占位标志（换成自己的标志请放 logo.png，或用菜单更换）
启动.bat             启动入口
使用说明.txt          给非开发者的使用说明
```

**这几个文件要一起带着，别拆散**（`watermark.pyw` 依赖后两个 .py）。

## 换标志

把新的透明底 PNG 放到工具目录下并命名为 `logo.png`（同名覆盖），或用菜单 **设置 → 更换标志图片…** 选一张（会自动拷成 `logo.png`）。
程序会自动把标志拆成「校徽」和「文字」两部分，分别处理深色底适配。

> `logo.png` 已在 `.gitignore` 里——你自己的标志（可能含机构信息）不会被提交。

## 已知问题

- **描边宽度**：因为标志是先缩到目标尺寸再描边，小尺寸下描边会比标称略细一点点（实测 6px 出 5px）。
- **极细纹理的背景**：预览是在缩略图上算的，若背景有很细的纹理，预览会比导出「略干净一点」。要看准确的用「查看原图」。
